# 前端 UI / UX 审查报告（2026-09-17）

审查方式：以「零基础小白」身份在浏览器中真实走查 注册 → 首页 → 训练工作台 → 判断画布 → 训练地图 → 复盘与复练 → 我的能力 → 模型设置 → 移动端（390px），逐屏截图记录；再对照 design-taste-frontend / stitch-design-taste 规则与代码定位复核。

**Design Read**：这是一个面向产品新人的多面板训练工具（software UI，非营销页）。目标语言应为「 calm / minimal / 高可读 」， leaning toward 单一无衬线显示体 + 单一强调色 + 克制动效。当前实现却用了「 editorial / luxury 」语言（宋体大标题、暖纸底、四色强调），与「训练健身房」的产品心智和「简约」诉求错位。

**当前 Dial 读数**：VARIANCE 4 / MOTION 2 / DENSITY 6。
**目标 Dial**：VARIANCE 4 / MOTION 3 / DENSITY 5（简约、安静、信息够用但不压迫）。

## 一、阻断零基础用户的问题（P0）

### P0-1 演示模式披露太晚且前后矛盾
- 现象：未配置模型时，聊天阶段顶部是**绿色**横幅「已连接服务端；评分会记录模型、场景与 Rubric 版本」，AI 只回通用教练话术；直到提交判断时才变成**粉色**横幅「当前使用离线演示引擎」。
- 后果：小白在「以为在和真实业务角色对话」的阶段其实拿到的是演示回复，产品核心价值（AI 角色扮演）静默失效，且「Rubric 版本」是术语泄漏。
- 位置：`app-shell.tsx`（runtime notice 渲染处）、`globals.css:750`。
- 方案：进入训练即显示一条中性提示「当前为演示模式：回复为示例剧本。配置模型后获得真实角色扮演」，并提供「去配置」入口；删除「Rubric 版本」等基础设施措辞；横幅颜色不随状态在绿/粉之间跳变。

### P0-2 主 CTA 全程呈「灰色死亡按钮」
- 现象：登录提交、发送追问、结束访谈、提交判断并查看反馈、保存、测试连接、创建团队、开始 2 分钟复练——全部为灰底禁用态，且**不说明解锁条件**。
- 后果：小白第一眼认为产品坏了；「下一步动作」文字与禁用按钮同屏矛盾（首页「下一步动作：先完成一个短场景」旁就是禁用的「开始 2 分钟复练」）。
- 方案：禁用态保留可读对比（ink 40% on line），并在按钮旁一行小字说明解锁条件（如「填写核心问题与建议行动后可提交」）；或改为可点击 + 点击后内联校验提示。禁止「文字说 A、按钮是禁用的 B」。

### P0-3 同屏四个互相矛盾的时长
- 现象：页头「用 5—10 分钟」、推荐卡 meta「6 分钟」、主 CTA「开始 3 分钟诊断」、次级卡「开始 2 分钟复练」。
- 后果：小白无法建立时间预期，信任受损。
- 位置：`src/lib/navigation.ts:24`、`app-shell.tsx` 推荐卡与 CTA。
- 方案：全站统一一个口径（场景预计时长），CTA 不再自带第二个时长数字。

### P0-4 判断画布与对话完全割裂
- 现象：结束访谈后是 8 个空白文本框（核心用户/当前流程/核心问题/…），刚才的对话内容**零带入**；唯一要求提示「至少填写核心问题与建议行动」在右上角、灰、小。
- 后果：小白面对 8 个抽象空框认知负荷爆炸，是闭环流失的最大单点。也违背产品原则「评分必须引用用户真实回答」。
- 方案：从对话自动预填草稿（或提供「带入我的原话」按钮逐字段插入）；把必填要求放到提交按钮旁而非右上角。

### P0-5 「切换账号 / 退出」一个按钮两个意图
- 位置：`app-shell.tsx` 侧栏底部。
- 后果：点击结果不可预期，小白最怕「点错就没了」。
- 方案：改为单一「退出登录」+ 用户头像/昵称下拉菜单承载切换账号。

### P0-6 反馈悬浮按钮遮挡内容
- 现象：1440px 下「反馈」FAB 压住右栏说明文字（「覆盖度只表示你是否问到了相关▮信息」）；390px 下压住主 CTA 区域。
- 位置：`globals.css:3341`（`.feedback-fab { position: fixed }`）。
- 方案：为右栏/主内容预留 FAB 安全区（padding-bottom / padding-right），或把反馈入口收进侧栏与设置菜单。

### P0-7 模型设置弹窗：无 dialog 语义、Esc 不关闭、向小白索要 API 密钥
- 现象：实测 Esc 无效；快照中无 `role="dialog"`/`aria-modal`；弹窗直接要求「API 密钥 / 模型名 gpt-4o-mini / deepseek-chat / qwen-plus」，无「跳过、继续演示」出口，无获取密钥指引。
- 位置：`llm-config-panel.tsx`、`app-shell.tsx`（弹窗挂载处，grep 确认无 Escape/keydown 处理）。
- 方案：补 `role="dialog" aria-modal="true"`、Esc 关闭、焦点陷阱；弹窗首屏先说明「不配置也能用演示模式」，把密钥表单收进二级披露。

### P0-8 移动端页头出现黑色描边框
- 现象：390px 下页头（H1 + 副标题 + 设置按钮）被一圈 2px 黑边框包住，像调试残留。
- 方案：修响应式 border 规则，移动端页头去框。
