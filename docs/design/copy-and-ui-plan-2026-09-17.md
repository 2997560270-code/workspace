# 文案歧义诊断 与 最终 UI 改法（2026-09-17）

## 二、最终 UI 改法（按屏）

### 0. 全局基线
- 字体：删 `--font-display` 衬线栈（globals.css:53），标题改无衬线 600；正文栈移除 Inter（:54）。
- 颜色：唯一强调深绿 #1F6F54；amber/coral 仅状态语义；删除训练地图 6 条彩虹 `border-left`（:342/:358/:384/:403/:406/:459）。
- 图标：Phosphor/Tabler 替换 ⚙ ● ↗ ▸（app-shell.tsx:98/1602/1629、voice-input-button.tsx:123、llm-config-panel.tsx:161），strokeWidth 1.5。
- 删除全部编号标签（侧栏 01-04、列表 01-05、空态 01）与 80% 的 eyebrow。
- 按钮三 tier（ink 实心 / 1px 描边 / ghost），禁用态保留可读对比 + 一行解锁提示。
- 每屏单一滚动上下文；FAB 预留 72px 安全区；弹窗补 `role="dialog"`+Esc+焦点陷阱。

### 1. 登录页
左栏：品牌标记只留一处；H1 无衬线两行；删英文 eyebrow；三个数据块改一句价值描述；hero 不超首屏。
右栏：tab 登录/注册；提交按钮「继续」；删底部重复注册链接；本地模式说明改白话（C9）。

### 2. 首页（今日训练）
- 页头：标题 + 一句白话副标题；右上角小状态（演示模式 / 已配置模型）。
- 唯一深色主卡：情境名 + 一句背景 + 单一时长 + 主 CTA「开始今日练习（约 6 分钟）」+ 次 CTA「先看情境背景」。
- 右栏：本周目标「0 / 5 次」纯文字；有数据后才画柱图。
- 第二卡：新人态单一引导「第一步：完成一次练习」，不再挂禁用复练按钮。
- 能力地图：5 行改紧凑分组，去编号、去重复 pill。
- 扩展入口（多人角色/自定义/课程/资源/测评/资料）收进「更多练习方式」折叠区，去彩虹边。

### 3. 训练工作台
- 顶栏：情境名 + 模式切换（诊断/严格/练习，各带一句话解释）+ 演示模式提示条（仅演示时）。
- 左栏：情境背景改可折叠 disclosure，取消嵌套滚动；返回按钮与标题分行。
- 中栏：actor 统一「AI 角色」；placeholder 给示例问句；「给我一点提示」改 ghost 描边按钮；发送按钮禁用带原因。
- 右栏：覆盖度改「已覆盖 n / 5 个信息维度」，提问命中即点亮对应维度（150ms scale-in）；结束按钮「结束对话，提交我的判断」+ 解锁说明。

### 4. 判断画布
- 顶部引导：「信息不足，暂不做决定」也是合理判断（从底部角落上移）。
- 必填说明移到提交按钮旁（C31）。
- 8 个字段提供「带入我的原话」从对话预填草稿。
- 提交后反馈页逐句挂接用户原话（落实产品原则 2）。

### 5. 复盘与复练 / 我的能力 / 训练地图
- 复盘：新人单一空态 + 主 CTA「开始首次训练」；有记录后列表 + 详情。
- 我的能力：新人态改「第一步」引导卡；团队表单移出本页；统计改白话（C34）；不再展示三组 0。
- 训练地图：首屏突出「今日推荐」1 张卡，其余按 5 项能力分组折叠；删 12 张同构卡与重复「未训练」pill。

### 6. 设置弹窗
首屏一句「不配置也能用演示模式」+「跳过」；密钥/模型名表单收进二级披露；补获取密钥指引链接；dialog 语义 + Esc。

### 7. 移动端
页头去黑框；FAB 安全区；全部多列单列折叠；触控目标 ≥44px。

## 三、落地顺序
1. 文案替换（C1-C35）：纯字符串改动，风险最低、收益最直接，先做。
2. P0 交互（禁用按钮解锁提示、退出按钮、FAB 安全区、弹窗 a11y、移动端黑框、演示模式披露）。
3. 视觉基线（字体、颜色收敛、图标、删编号/eyebrow）。
4. 结构改造（画布预填、覆盖度反馈、地图分组、我的能力新人态、模式切换上移）。
