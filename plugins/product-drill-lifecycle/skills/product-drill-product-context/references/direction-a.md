# Direction A reference

## Positioning
Product Drill is an AI product-discovery training gym for product newcomers, career switchers, and PMs with 0–3 years of experience.

## JTBD
When a learner lacks safe access to real discovery work, they use a short simulated scenario to practice questioning and judgment, receive evidence-based feedback, and retry the exact weak behavior.

## Core skills
- user and role identification
- current workflow and context
- problem impact and root cause
- existing alternatives
- success metrics

## Product principles
- train behavior, not memorized frameworks
- cite message evidence for every ability claim
- separate simulated facts from real user evidence
- compare like-for-like scenario, rubric, and model versions
- practice-mode evidence does not equal independent mastery
- low confidence yields “more evidence needed,” not false precision

## North-star event
A user completes a training, views evidence, completes a targeted retry, and records an observable improvement.

## Non-goals for the current phase
Enterprise admin, community, courses, multi-model routing, custom scenarios, voice, payments, and generic AI product analysis.
