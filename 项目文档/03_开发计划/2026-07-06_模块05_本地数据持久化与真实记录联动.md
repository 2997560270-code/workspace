# 模块05 本地数据持久化与真实记录联动 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让产品档案、AI 理解修正、训练历史和能力画像数据在浏览器刷新后仍然保留，并让历史页与能力页优先使用真实记录。

**Architecture:** 在正式前端工程中新增一个轻量 localStorage 存储适配层，用版本化 key 保存产品档案和训练历史。`ProductDrillApp` 负责初始化读取、状态变更后写入；历史页和能力页继续读取同一份状态，保持 Demo V3 页面结构不变。

**Tech Stack:** Next.js App Router、React state、TypeScript、Vitest、Playwright、localStorage。

## 验收标准

1. 新增产品后刷新页面，产品档案不丢失。
2. 修正 AI 理解后刷新页面，修正内容不丢失。
3. 训练提交方案后刷新页面，历史页仍能看到该训练记录。
4. 能力页至少能根据真实训练记录显示完成训练数量、平均分和高频短板。
5. 现有 Demo V3 布局、按钮位置和黑底白字按钮规则不改变。
6. `npm.cmd test` 通过。
7. `npm.cmd run e2e -- tests/e2e/app-shell.spec.ts` 通过。
8. `npm.cmd run build` 通过。

## 人工测试方式

1. 打开正式 MVP 前端。
2. 进入产品页，新增一个产品并保存。
3. 刷新浏览器，确认新增产品仍存在。
4. 进入训练页，点击确定，输入业务，提交方案。
5. 刷新浏览器，进入历史页，确认训练记录仍存在。
6. 进入能力页，确认完成训练数量与真实训练记录一致。
