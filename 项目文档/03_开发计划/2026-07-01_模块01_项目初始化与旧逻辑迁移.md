# 模块 01：项目初始化与旧逻辑迁移开发计划

创建时间：2026-07-01

## 目标

在正式工程 `product-drill-mvp/apps/web` 中建立可运行的前端测试环境，并迁移旧项目中已经通过测试验证的纯业务逻辑，为后续严格按 Demo V3 UI 开发打基础。

## 本模块包含

1. 初始化 `apps/web` 的最小 Next/Vitest/Playwright 工程配置。
2. 先写旧逻辑迁移单元测试。
3. 确认测试因目标模块不存在而失败。
4. 迁移训练、产品、评估、历史、能力画像和登录基础逻辑。
5. 跑通单元测试。

## 本模块不包含

1. 不改 `demov3.html`。
2. 不重构 Demo V3 页面 UI。
3. 不接入真实 AI 接口。
4. 不接入数据库。
5. 不上传 GitHub 或飞书，除非用户另行要求。

## 测试先行要求

先创建以下测试：

- `tests/unit/training-session.test.ts`
- `tests/unit/product-analysis.test.ts`
- `tests/unit/evaluation.test.ts`
- `tests/unit/training-history.test.ts`
- `tests/unit/ability-profile.test.ts`
- `tests/unit/auth.test.ts`

测试失败原因应为目标模块未实现或未迁移。

## 验收标准

1. `npm.cmd test` 能在 `apps/web` 下通过。
2. 旧核心逻辑已迁移到正式工程目录。
3. 不影响现有 Demo V3 静态文件。
4. 用户后续能基于该工程继续开发正式 MVP。
