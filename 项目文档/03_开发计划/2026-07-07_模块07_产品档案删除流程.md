## 1. 背景

“我的产品”页面已有“删除产品”按钮，但当前按钮没有真实删除行为。用户需要能够删除不再需要的产品档案，并确保删除后的产品列表、AI 解读区域和本地保存数据保持一致。

## 2. 目标

完成后，用户可以在产品档案页进入删除模式，选择要删除的产品，再点击删除按钮完成删除，并在刷新后保持删除结果。

## 3. 本次包含

- 删除模式入口：点击“删除产品”后进入删除模式。
- 多选删除动作：进入删除模式后按钮文案变为“删除”，用户可连续选择多个产品，再一次性删除。
- 删除后选择回退：删除多个产品后自动选中剩余产品；没有产品时显示空状态。
- 本地持久化：删除结果写入 localStorage。

## 4. 本次不包含

- 不做二次弹窗确认。
- 不做批量删除。
- 不做云端数据库删除。

## 5. 用户流程

```text
用户进入产品页 → 点击删除产品 → 页面进入删除模式 → 用户选择一个或多个要删除的产品 → 点击删除 → 产品从档案列表移除 → AI 解读区域同步切换或显示空状态
```

## 6. 页面与交互规则

### 默认状态

产品档案左侧显示产品列表、添加产品按钮和删除产品按钮。

### 操作状态

点击“删除产品”后进入删除模式：

- 删除按钮文案变为“删除”。
- 产品列表仍可点击选择，且可多选；再次点击已选产品可取消选择。
- 点击“删除”后删除所有已选中的产品。

### 异常状态

- 没有产品时，产品解读区域显示“暂无产品”。
- 删除最后一个产品后，列表为空，用户可继续点击“添加产品”。

## 7. 数据规则

- 删除后更新 `product-drill:mvp:products`。`n- 删除列表按已勾选产品 ID 集合过滤。
- 当前选中产品如果被删除，自动切换到剩余第一个产品。
- 如果无剩余产品，选中 ID 置空。

- 用户能进入产品删除模式。

- 刷新后删除结果仍保留。

## 10. 风险与处理

| 风险 | 表现 | 处理方式 |
|---|---|---|
| 误删 | 用户点错产品 | 本次按用户已确认的两步删除模式处理，后续可加二次确认 |
| 删除后选中 ID 失效 | 页面空白或报错 | 删除后自动选择剩余第一个产品 |
| 本地存储未更新 | 刷新后产品恢复 | 删除时同步写入 localStorage |
