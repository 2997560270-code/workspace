# 模块06：历史详情与复盘联动开发计划

## 目标

让历史页面从静态复盘展示升级为真实记录联动：用户点击左侧任一训练记录后，右侧复盘区域同步展示该记录的场景、模式、评分、关键对话和 AI 点评，并支持生成复盘报告与返回训练。

## 开发原则

- 保持 Demo V3 页面结构，不移动主要模块位置。
- 只增强历史页交互，不重构训练、产品和能力页。
- 按测试先行执行：先写 E2E 失败测试，再开发，再完整验证。
- 历史列表仍保留默认样例记录，真实训练记录优先展示在列表顶部。

## 测试点

1. localStorage 中存在多条训练记录时，历史页左侧显示这些记录。
2. 点击第二条真实记录后，右侧复盘面板切换为该记录内容。
3. 右侧展示该记录评分、关键对话和 AI 点评问题。
4. 点击“生成复盘报告”后，页面显示该记录的复盘报告摘要。
5. 点击“重新训练此场景”后，跳转到训练页面。

## 验收标准

- 历史页不再固定展示“企业培训服务需求澄清”。
- 选择不同真实历史记录时，右侧复盘内容同步变化。
- 新增 E2E 测试覆盖历史详情联动。
- `npm.cmd test` 通过。
- `npm.cmd run e2e -- tests/e2e/app-shell.spec.ts` 通过。
- `npm.cmd run build` 通过。
