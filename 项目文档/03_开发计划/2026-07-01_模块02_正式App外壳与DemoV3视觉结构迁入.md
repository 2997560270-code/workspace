# 模块 02：正式 App 外壳与 Demo V3 视觉结构迁入开发计划

创建时间：2026-07-01

## 目标

在正式工程 `product-drill-mvp/apps/web` 中建立可运行的 MVP App 外壳，严格按照已确认的 Demo V3 风格迁入基础页面结构，为后续逐个功能模块开发提供统一布局。

## 重要约束

1. 不修改原始 `demov3.html`。
2. 不移动 Demo V3 中已经确认的模块和交互按钮位置。
3. 本模块只迁入正式 App 的视觉结构和基础导航，不实现深层业务功能。
4. 继续沿用测试先行流程。

## 本模块包含

1. 创建 Next App 首页入口。
2. 创建正式 App 外壳：左侧动态导航、顶部标题区、主内容区。
3. 创建 6 个基础页面结构：
   - 首页
   - 训练
   - 产品
   - 添加产品
   - 历史
   - 能力
4. 保持 Demo V3 已确认的关键结构：
   - 首页产品介绍、核心功能、核心数据表达。
   - 训练页左侧训练设置、中间 AI 客户模拟、右侧 AI 判断。
   - 产品页左侧产品档案、中间 AI 产品解读、右侧成熟度评估。
   - 添加产品页产品资料和 AI 追问澄清。
   - 历史页训练记录顶部参数、右侧记录复盘。
   - 能力页趋势、维度、高频短板、下一步推荐训练。
5. 创建模块02 E2E 测试和手动测试入口。

## 本模块不包含

1. 不接入真实 AI。
2. 不做数据库持久化。
3. 不做文件真实解析。
4. 不做最终业务功能闭环。
5. 不同步 GitHub 或飞书，除非用户另行要求。

## 测试计划

先写 E2E 测试：

- 首页能打开并显示 Product Drill、首页标题和核心模块。
- 左侧导航可以切换训练、产品、历史、能力页面。
- 训练页初始显示“请选择您的训练设置。”和“确定”按钮。
- 产品页保持产品档案、AI 产品解读、成熟度评估三栏结构。
- 历史页训练记录顶部显示 24、6、+6.4 三个参数。
- 能力页显示最近训练表现趋势、能力维度表现、高频短板和下一步推荐训练。

首次运行应失败，随后实现页面使测试通过。

## 验收标准

1. `npm.cmd test` 继续通过。
2. 模块02 E2E 测试通过。
3. 手动打开正式 App 能看到 Demo V3 风格的页面外壳。
4. 原始 `demov3.html` 未被修改。
