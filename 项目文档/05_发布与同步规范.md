4. 不包含 `归纳总结/`。
5. 不包含临时调试文件。

## 4. 同步记录格式

```markdown
# YYYY-MM-DD_同步记录

## 同步目标

- 本地 workspace
- GitHub
- 飞书

## 同步文件

- 文件 1
- 文件 2

## GitHub 结果

- 分支：master
- 提交号：填写提交号
- 推送结果：成功 / 失败

## 飞书结果

- 文件夹：workspace
- 文件列表确认：成功 / 失败

## 未同步内容

- 本地-only 文件
- 临时文件

## 问题与处理

记录同步时遇到的问题和解决方式。
```

## 6. 不同步规则

以下内容不推送 GitHub，不同步飞书：

- `.codegraph/`
- 临时截图
- 临时上传包
