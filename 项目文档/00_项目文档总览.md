# Product Drill 项目文档总览

这个目录用于集中存放 Product Drill 后续开发相关文档。后续需求、设计、开发计划、测试验收、发布同步、版本记录，都优先放在这里，避免散落在 workspace 根目录。

## 目录结构

```text
项目文档/
├─ 00_项目文档总览.md
├─ 01_项目文档规范.md
├─ 02_开发流程规范.md
├─ 03_模块文档模板.md
├─ 04_测试与验收规范.md
├─ 05_发布与同步规范.md
├─ 01_需求与决策/
├─ 02_产品与交互/
├─ 03_开发计划/
├─ 04_测试与验收/
├─ 05_发布与同步/
├─ 06_版本记录/
└─ 99_归档/
```

## 使用原则

1. 每次新增功能前，先在 `03_开发计划/` 写开发计划。
2. 每个模块遵循“先写测试，再开发，再 e2e，再人工验收”。
3. 与产品方向、交互选择、范围取舍有关的内容，放入 `01_需求与决策/`。
4. 与 UI、页面结构、交互流程有关的内容，放入 `02_产品与交互/`。
5. 每次测试方法、验收入口、验收结果，放入 `04_测试与验收/`。
6. GitHub、飞书、本地 workspace 的同步规则和结果，放入 `05_发布与同步/`。
7. 版本标签、版本说明、回退点，放入 `06_版本记录/`。
8. 已废弃但仍需保留参考的文档，移动到 `99_归档/`。

## 文档状态标识

- `草稿`：内容正在整理，仅供讨论。
- `待审核`：需要用户确认后才能进入开发。
- `已确认`：可以作为开发依据。
- `开发中`：对应模块正在实现。
- `待验收`：开发完成，等待人工测试。
- `已验收`：用户确认通过。
- `已归档`：不再作为当前开发依据，只保留参考。
